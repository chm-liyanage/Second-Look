# SecondLook

*Topic* : **Think Before You Click: Spotting Fake News and Scams**.

## What This Includes

- **Overview:** An interactive inbox preview that shows hidden phishing traps, plus four common scam tactics.
- **Scam Lab:** Three realistic scam messages (email, SMS, and direct message) where you click to find 9 red flags.
- **Fact Check:** Three social media posts with source, date, and official record clues to help you tell real alerts from misleading or fake posts.
- **Link Checker & Guide:** A browser-based URL checker that reveals the real website owner behind a link, a 4-step pause routine, and a 6-habit safety checklist saved in local storage.

## How to Run

Open `index.html` directly in any web browser. or
Open `https://chm-liyanage.github.io/Second-Look/`
